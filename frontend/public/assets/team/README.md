# Aset Foto Tim LUMORA (`public/assets/team`)

Simpan foto individu anggota tim di folder ini dengan penamaan berikut:

- `team-member-1.webp`
- `team-member-2.webp`
- `team-member-3.webp`
- `team-member-4.webp`
- `team-member-5.webp`

## Spesifikasi Foto yang Disarankan
- **Rasio aspek:** `4:5` (potret vertikal, misalnya `800 × 1000 px` atau `1200 × 1500 px`)
- **Format:** `.webp` (atau `.jpg` / `.png` — sesuaikan ekstensi pada `frontend/data/team.ts`)
- **Pengaturan Data:** Perbarui nama lengkap, jabatan, dan deskripsi singkat pada `frontend/data/team.ts`.
